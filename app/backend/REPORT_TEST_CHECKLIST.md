## Настройка формы отчета

### 1. Диапазон дат
- **Период 1**: `2023-01-01` до `2023-12-31` (весь 2023 год)
- **Период 2**: `2024-01-01` до `2024-12-31` (весь 2024 год)
- **Период 3**: `2025-01-01` до `2025-12-31` (весь 2025 год)
- **Период 4**: `2023-11-01` до `2025-01-31` (пересечение нескольких лет)

### 2. Департаменты
- Выбрать **1 департамент** (для проверки суммирования по одному)
- Выбрать **2-3 департамента** (для проверки суммирования по нескольким)
- Выбрать **все департаменты** (для проверки полного отчета)

## Проверка результатов в Excel

### Структура отчета

1. ✅ **Строка 1**: Заголовок с диапазоном дат (жирный, размер 18)
   - Формат: "Результаты работы [месяц] [год] - [месяц] [год]"
   - Пример: "Результаты работы ноябрь 2023 - январь 2025"

2. ✅ **Строка 2**: Заголовки столбцов
   - Столбец 1: "№" (светло-зеленый фон)
   - Столбец 2: "Показатель" (светло-зеленый фон)
   - Столбцы 3+: Названия департаментов (светло-зеленый фон)

3. ✅ **Группы** (светло-зеленый фон, жирный шрифт)
   - Столбец 1: Номер группы (1, 2, 3)
   - Столбец 2: Название группы
   - Столбцы 3+: Сумма всех значений в группе по департаментам

4. ✅ **Подгруппы** (жирный шрифт)
   - Столбец 1: Номер подгруппы (1.1, 1.2, 1.3, ...)
   - Столбец 2: Название подгруппы
   - Столбцы 3+: Сумма всех значений в подгруппе по департаментам

5. ✅ **Subsubgroups** (если есть)
   - Столбец 1: Номер subsubgroup (1.1.1, 1.1.2, 1.1.3, ...)
   - Столбец 2: Пусто
   - Столбцы 3+: Сумма всех значений в subsubgroup по департаментам

6. ✅ **Детальные поля**
   - Столбец 1: Номер subsubgroup (если есть) или пусто
   - Столбец 2: Название поля (label)
   - Столбцы 3+: Значение по департаментам

## SQL запросы для проверки данных

### Проверка количества событий с is_service_investigation = true
```sql
SELECT COUNT(*) FROM events 
WHERE is_service_investigation = true 
AND createdAt BETWEEN '2023-01-01' AND '2023-12-31';
```

### Проверка суммы detected_damage по департаментам
```sql
SELECT department_id, SUM(detected_damage) as total
FROM events
WHERE createdAt BETWEEN '2023-01-01' AND '2023-12-31'
GROUP BY department_id;
```

### Проверка суммы total_debt из operational_activities
```sql
SELECT department_id, SUM(total_debt) as total
FROM operational_activities
WHERE createdAt BETWEEN '2023-01-01' AND '2023-12-31'
GROUP BY department_id;
```
