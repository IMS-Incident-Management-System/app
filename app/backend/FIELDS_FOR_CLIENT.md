# Полный список полей для отчетов

Документ содержит все доступные поля из трех сущностей системы для формирования отчетов.

## 1. ИНЦИДЕНТЫ (Incident)

### Булевы поля (считаются как количество записей где поле = true)
- `is_db` - Особо важно (1ДБ). Указывает на особый статус инцидента, требующий специальной обработки

### Числовые поля (суммируются)
- `detected_damage` - Выявлен ущерб (руб.)
- `recovered_damage` - Возмещен ущерб (руб.)
- `prevented_damage` - Предотвращен ущерб (руб.)
- `additional_income` - Получен дополнительный доход (руб.)
- `reduced_cost` - Снижена стоимость товаров, работ и услуг на сумму (руб.)

---

## 2. СОБЫТИЯ (Event)

### Булевы поля (считаются как количество записей где поле = true)
- `is_service_investigation` - Служебные расследования
- `is_service_investigation_ib` - Служебные расследования ИБ
- `is_service_investigation_bpio` - Служебные расследования БПиО
- `is_service_investigation_bpio_hotline` - Служебные расследования БПиО (горячая линия)
- `is_service_check` - Служебные проверки
- `is_service_check_ib` - Служебные проверки ИБ
- `is_service_check_bpio` - Служебная проверка БПиО
- `is_service_check_bpio_hotline` - Служебная проверка БПиО (горячая линия)
- `is_verification_activity` - Проверочные мероприятия
- `is_db` - Особо важно (1ДБ). Указывает на особый статус события, требующий специальной обработки

### Числовые поля (суммируются)
- `detected_damage` - Выявлен ущерб (руб.)
- `recovered_damage` - Возмещен ущерб (руб.)
- `prevented_damage` - Предотвращен ущерб (руб.)
- `additional_income` - Получен дополнительный доход (руб.)
- `reduced_cost` - Снижена стоимость товаров, работ и услуг на сумму (руб.)
- `prevented_unnecessary_writeoff` - Предотвращено необ. списание ДЗ, руб.
- `vat_deducted` - Принят к вычету НДС, руб.

---

## 3. ОПЕРАЦИОННАЯ ДЕЯТЕЛЬНОСТЬ (OperationalActivity)

### ЭБ - Работа по возмещению ДЗ и НДС (DEBT_RECOVERY)
- `total_debt` - Общий размер дебиторской задолженности (руб.)
- `overdue_debt` - Общий размер просроченной дебиторской задолженности (руб.)
- `overdue_debt_sb` - в том числе размер ПДЗ, переданный в работу (руб.)
- `recovered_debt` - Взыскано ДЗ при участии подразделений (руб.)
- `available_vat` - Общая сумма доступного к возмещению, но не возмещенного НДС (руб.)
- `vat_assistance` - Содействие в получении документов для возмещения НДС (кол-во)
- `written_off_debt` - Общий размер списанной дебиторской задолженности (руб.)

### ЭБ - Взаимодействие с правоохранительными органами (LAW_ENFORCEMENT)
- `incoming_requests` - Поступило входящих запросов (кол-во)
- `executed_requests` - Исполнено запросов (кол-во)
- `executed_tasks` - Исполнено заданий (кол-во)
- `received_presentations` - Поступило представлений (кол-во)
- `executed_presentations` - Исполнено представлений (кол-во)

### ЭБ - Контроль инвестиционной, закупочной и договорной деятельности (INVESTMENT_CONTROL)
- `checked_entities_new` - Проверено юр. и физ.лиц перед заключением новых договоров (кол-во)
- `negative_conclusions_new` - из них дано отрицательных заключений по новым договорам (кол-во)
- `checked_entities_active` - Проверено контрагентов с действующими договорами (кол-во)
- `negative_conclusions_active` - из них дано отрицательных заключений по действующим договорам (кол-во)
- `checked_draft_contracts` - Проверено проектов договоров, доп. соглашений (кол-во)
- `not_approved_drafts` - из них не согласовано (кол-во)
- `checked_active_contracts` - Проверено действующих договоров, доп. соглашений (кол-во)
- `not_approved_active` - из них не согласовано (кол-во)
- `planned_budget` - Сумма запланированного бюджета закупок (руб.)
- `procurement_procedures_count` - Проведено закупочных процедур (кол-во)
- `single_source_count` - использован способ "единственный источник" (кол-во)
- `procurement_procedures_sum` - Проведено закупочных процедур на сумму (руб.)
- `single_source_sum` - использован способ "единственный источник" на сумму (руб.)

### ЭБ - Работа по выявлению признаков аффилированности (AFFILIATION)
- `checked_employees` - Проверено сотрудников (кол-во)
- `found_affiliated` - Выявлено аффилированных (кол-во)
- `checked_candidates` - Проверено кандидатов на трудоустройство (кол-во)
- `rejected_candidates` - Отклонено кандидатов (кол-во)
- `rejected_affiliated` - Отклонено аффилированных (кол-во)

### ЭБ - Работа с обращениями граждан (CITIZEN_APPEALS)
- `total_appeals` - Проверено обращений граждан и юр. лиц (кол-во)
- `zon_applications` - Заявлений абонентов о непричастности к договору (кол-во)
- `fictitious_contracts` - Выявлено фиктивных договоров (кол-во)
- `termination_requests` - Заявлений о расторжении договора и возврате ДС (кол-во)
- `beautiful_numbers` - Запросов на переоформление "красивых" номеров (кол-во)
- `sim_replacement` - Заявлений о неправомерной замене SIM-карт (кол-во)
- `refund_requests` - Заявлений о возврате ошибочного платежа (кол-во)
- `other_appeals` - Прочих заявлений абонентов (кол-во)

### ИБ - Сведения об участии в проверочных мероприятиях (INSPECTIONS)
- `ib_incident_checks` - проверок по инцидентам ИБ (кол-во)
- `planned_ib_checks` - плановых проверок ИБ (кол-во)
- `non_compliances` - несоответствий нормативным документам (кол-во)

### ИБ - Меры, принятые к нарушителям (VIOLATORS_MEASURES)
- `warnings` - Вынесено предупреждений (кол-во)
- `remarks` - Вынесено замечаний (кол-во)
- `reprimands` - Вынесено выговоров (кол-во)
- `dismissals` - Уволено сотрудников (кол-во)

### ИБ - Количество согласованных доступов (ACCESS_APPROVALS)
- `approved_accesses` - Согласовано доступов (кол-во)

### ИБ - Подготовлено служебных записок (MEMOS_PREPARED)
- `memos_count` - Подготовлено служебных записок (кол-во)

### ИБ - События и мероприятия (RISK_MINIMIZATION)
- `scanned_count` - Проведено/просканировано (кол-во)
- `vulnerabilities_found` - Выявлено уязвимостей (кол-во)

### ИБ - Реализация режима защиты КТ и КИ (CT_KI_PROTECTION)

### ИБ - Контроль доступа к ИС (ACCESS_CONTROL)
- `access_requests` - Рассмотрено заявок на предоставление доступа (кол-во)
- `access_violations` - Зафиксировано нарушений (кол-во)

### ИБ - Мониторинг инцидентов ИБ (INCIDENT_MONITORING)

## Примечания

1. **Булевы поля** - считаются как количество записей, где поле = true
2. **Числовые поля** - суммируются по выбранным департаментам за указанный период
3. **Период** - фильтрация происходит по полю `createdAt` (дата создания записи)
4. **Департаменты** - данные группируются и суммируются по выбранным департаментам

## Задача для клиента

Пожалуйста, укажите для каждого поля:
1. **Название для отчета** (как должно отображаться в Excel)
2. **Группа** (к какой группе относится поле, например: "Проведение мероприятий, проверок и расследований")
3. **Подгруппа** (если нужна, например: "Проведено служебных проверок и расследований")
4. **Порядок сортировки** (если важен порядок полей в группе/подгруппе)

Можно использовать формат:
```
Поле: detected_damage (Incident)
Название: Выявлен ущерб (руб.)
Группа: 1. Проведение мероприятий, проверок и расследований
Подгруппа: 1.4. Выявлен ущерб
Порядок: 1
```
