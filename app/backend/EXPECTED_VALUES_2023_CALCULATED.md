## Важные замечания

⚠️ **Внимание:** Эти значения являются **приблизительными**, так как:
1. Данные распределяются случайно по годам
2. Финансовые значения тоже случайные в указанных диапазонах
3. Реальные значения могут отличаться на ±20-30%

Для получения **точных значений** используйте SQL запросы из файла `EXPECTED_VALUES_2023.md` после запуска сидера.

## Как проверить

1. Запустите сидер: `make seed-report`
2. Выполните SQL запросы из `EXPECTED_VALUES_2023.md`
3. Сравните результаты с Excel отчетом
4. Значения должны совпадать с точностью до округления
