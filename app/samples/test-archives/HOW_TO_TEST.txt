# Как проверить архив / Авто

1. Генератор → «Архив Excel».
2. Загрузить: test_01 → test_02 → test_03 (все ок).
3. test_04_OVERLAP — должен отклониться (пересечение с январём).
4. test_05_replace_jan_v2 — ок, новая версия января (222 вместо 111).
5. Период 01.01.2025 — 31.05.2025, режим «Авто»:
   янв=222 (или 111), март=333, май=555; февраль и апрель = live системы.
6. Режим «Архив» на тот же диапазон — только Excel-снимки (без live-пробелов).

- test_01_jan_2025.xlsx: «Результаты работы 01.01.2025-31.01.2025», marker=111 — Январь — загрузить первым
- test_02_mar_2025.xlsx: «Результаты работы 01.03.2025-31.03.2025», marker=333 — Март — без пересечения; февраль в Авто = live
- test_03_may_2025.xlsx: «Результаты работы 01.05.2025-31.05.2025», marker=555 — Май — ещё один непересекающийся кусок
- test_04_OVERLAP_jan_feb.xlsx: «Результаты работы 15.01.2025-15.02.2025», marker=999 — ДОЛЖЕН ОТКЛОНИТЬСЯ, если уже есть test_01
- test_05_replace_jan_v2.xlsx: «Результаты работы 01.01.2025-31.01.2025», marker=222 — Тот же период, что test_01 — новая версия (222 вместо 111)
