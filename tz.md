1.      Описание проекта
система управления инцидентами и событиями для компании. Позволяет пользователям фиксировать, редактировать, согласовывать инциденты, создавать события, анализировать данные и выгружать отчеты.
2.      Цель проекта
·         Автоматизировать процесс управления инцидентами и событиями
·         Упростить согласование инцидентов
·         Обеспечить аналитику и отчетность
 
3.      Основные термины
Инцидент – зарегистрированное событие, требующее внимание
Событие – действие, которое может быть как связано с инцидентом, так и существовать само по себе
Согласование – подтверждение инцидента ответственным лицом
Роль – уровень доступа пользователя
4.  	Архитектура проекта
 
·  	Frontend – React + TypeScript, Redux
·      Backend – Node js, Express js, PostgreSQL
·  	Авторизация – Keycloak
·  	Формат данных: JSON API, выгрузка в Excel
 
5.      Описание платформы
5.1 Описание платформы и взаимодействие с ней
Платформа позволяет пользователям:
·         Создавать, редактировать, согласовывать инциденты
·         Создавать события, привязывать их к инцидентам
·         Фильтровать данные по регионам, компаниям, статусам
·         Анализировать данные через дашборды и отчеты
·         Выгружать таблицу в Excel
5.2 Основные роли
1.  	Начальник СБ региона – создает инциденты, редактирует
2.  	Начальник СБ ФО – согласовывает инциденты, редактирует
3.  	Дежурный ОДС – создает инциденты, но не отправляет на согласование
4.  	Администратор – управляет пользователями, ролями, инцидентами, событиями
5.  	Другие роли – Доступ на основе требований

7.11 Создание события через инцидент
В карточке инцидента есть контейнер с событиями, которые привязаны к инциденту и кнопка создать событие. При нажатии на кнопку создать событие проваливаемся в страницу создания события. Событие, созданное через инцидент, «привязывается» к инциденту и является дочерним по отношению к инциденту. Привязать событие к инциденту другим способом нельзя. После создания события, оно появляется в инциденте в контейнере привязанных событий.
